    자세히
    값부터 적으면 col1 같은 임시 이름이 붙습니다. 비워 둔 열은 JSON에 나오지 않습니다.

    자세히
    긴 표에서는 Ctrl+↓로 그 줄에 바로 갑니다.
  3. 3열 타입 — ID · String · Int · Float · Bool · Enum. JSON에 그 타입으로 나갑니다("900"이 아니라 900).
    자세히
    새 열은 처음 적은 값으로 타입이 정해지고, 드롭다운에서 바꿉니다. 바꿔도 값은 그대로이고 맞지 않으면 빨간 칸입니다. Enum은 그 열에 적힌 값들이 목록이라, 앞 글자를 치면 나머지가 흐리게 보여 Enter · Tab으로 채웁니다. JSON에는 글자로 나갑니다.
  4. 4빨간 칸 — 타입에 맞지 않는 값입니다(천원). 위쪽에 오류 개수가 뜹니다.
  5. 5문A 번역해서 채우기 — 다른 열(Korean)을 번역해 이 열(English)을 채웁니다. Chrome PC에서 무료로 됩니다.
    자세히
    원문 열과 언어만 고르면 원문 언어는 알아서 찾습니다. 이미 적힌 칸이 있으면 덮어쓰기 전에 묻고, Ctrl+Z 한 번으로 되돌립니다. 브라우저 내장 번역이라 글이 PC 밖으로 나가지 않고, 처음 한 번은 언어 파일을 받습니다. 기계 번역이니 한 번 확인해 주세요.
칸 고르기와 고치기 — 클릭해 고르고, 그대로 치면 새로 씁니다. 일부만 고치려면 더블클릭 · F2. Esc 취소 · Delete 비우기 · Ctrl+Z 되돌리기. 키 전체는 보기 · 단축키에.
자세히
열은 글자에 맞춰 넓어집니다. 컬럼 이름 칸의 오른쪽 경계를 끌어 너비를 정하고, 두 번 누르면 되돌립니다.
엑셀 표가 있다면 — 엑셀에서 Ctrl+A → Ctrl+C 한 뒤 빈 곳에서 Ctrl+V. 첫 줄이 컬럼 이름이 됩니다.
자세히
값을 보고 열 타입을 정합니다. 엑셀이 붙이는 1,000 같은 쉼표와 TRUE / FALSE도 알아봅니다.

  1. 1ID는 정수 — 비었거나 숫자가 아니거나 다른 행과 겹치면 빨간 칸입니다.
  2. +번호 이어서 적기 — 마지막 ID에서 Enter를 누르면 새 줄에 다음 번호가 미리 채워집니다. 10씩 적었으면 10씩 이어 갑니다.
    자세히
    위 두 줄의 차이를 씁니다. 차이가 100을 넘으면 다른 구간으로 건너뛴 것으로 보고 1씩입니다. 이미 있는 번호는 건너뜁니다. 여러 줄을 한 번에 만들려면 채우기를 쓰세요.
  3. 2⚙ 접두사 — item_처럼 적으면 칸 앞에 이름표가 붙습니다. JSON에는 1001로 나갑니다.
    자세히
    JSON에 포함을 켜면 "item_1001" 문자로 나갑니다. 설정이 있으면 ⚙가 파랗게 보입니다.
  4. 3정렬 — ▼ 오름차순, ▲ 내림차순. 번호를 고치면 그 행이 제자리로 가고 화면이 따라갑니다.
  5. 4노란 칸 — 다른 테이블이 같은 자릿수의 ID를 쓴다는 알림입니다. 저장은 막지 않습니다.
    자세히
    테이블마다 100단위, 1000단위처럼 자릿수를 나눠 쓰면 겹치지 않습니다.
  6. 5⚙ 첫 자리로 색 구분 — ID 첫 자리(1~9)마다 색 띠를 보여 줍니다. 화면에만 보입니다.
    자세히
    1xxx 씨앗 · 8xxx 업그레이드처럼 첫 자리로 종류를 나눈 표에서 구간이 한눈에 보이고, 잘못 매긴 번호가 튑니다. 동그라미는 색과 자리의 짝입니다(표에 없는 자리는 테두리만). 테이블마다 켜고 끕니다.
ID가 없는 테이블 — Config처럼 한 줄짜리 표는 ID 열을 지우면 됩니다.
자세히
다른 열의 타입을 ID로 바꾸면 그 열이 맨 앞으로 가서 ID가 됩니다.

    자세히

  2. 2🔗 가져온 열 — 이름이 같은 열은 대상 값으로 채워지고 회색으로 잠깁니다.
  3. 3🔗 끄기 — 누르면 연결이 끊겨 직접 고칠 수 있습니다. 다시 누르면 대상 값으로 채워집니다.
    자세히
    연결 전에 적어 둔 값이 있었으면 그 값으로 돌아갑니다.

  5. +ID 불러오기 — 대상에만 있는 ID를 ⚙의 ID 불러오기 (N)로 새 줄로 가져옵니다.
    자세히
    여러 테이블을 참조하면 고르는 창이 뜨고, 이미 다 불러온 테이블은 회색으로 꺼져 있습니다. Ctrl+Z 한 번으로 되돌립니다.

# items

무기 아이템 목록. 상점·드롭에서 사용

| 컬럼 | 타입 | 설명 |
|---|---|---|
| id | ID · Int (작성 시 접두사 `item_`) | 고유 번호. 1000번대 무기 |
| name | String | 표시 이름 |
| price | Int | 상점 판매가 |
| kind | Enum: 검, 활, 지팡이 | 무기 종류 |
  1. 1적기 — 테이블 설명 버튼을 누르면 아래에 창이 열립니다. ↓ · Enter · Tab으로 다음 칸.
    자세히
    ↑ · Shift+Enter · Shift+Tab은 이전 칸입니다. Enum 열은 Enum · N개 ▾로 값 목록을 펼칩니다.
  2. 2Meta 시트 붙여넣기 — Column · Description · Type 시트를 복사해 이 창에 붙이면 한 번에 채워집니다.
    자세히
    컬럼명 · 설명 · 타입처럼 한국어 머리줄도 알아봅니다.
  3. 3설명서 내보내기 — 파일 저장 ▾ → 설명서 (.md)…. 이름은 ItemDataTable_Desc.md입니다.
    자세히
    JSON과 이름이 같으면 Unity Resources.Load가 헷갈려서 _Desc를 붙입니다. 예전 이름(ItemDataTable.md)도 불러오고, 커밋하면 새 이름으로 바꿔 올립니다.
  4. 4설정 되살리기 — JSON과 설명서를 함께 불러오면 타입 · 접두사 · 참조 설정도 돌아옵니다.

불러오기 · 저장

어디서 가져오든 목록 창에서 파일마다 들어갈 곳을 먼저 보여 줍니다. 지금 탭은 덮어쓰지 않습니다.

  1. 1GitHub — 팀 저장소의 폴더에서 바로 가져옵니다. 팀으로 쓰기 참고.
  2. 2파일 — 여러 개도 됩니다. JSON · CSV 하나면 바로 새 탭으로 열립니다.
  3. 3폴더 — Unity의 Json 폴더를 통째로 고릅니다(.meta · 엑셀은 뺌).
    자세히
    이름 순서로 열리니 탭을 끌어 순서를 바꾸세요.
  4. 4JSON… · 설명서… — 저장할 탭을 고릅니다. 여러 개면 zip 하나. 오류가 있으면 먼저 묻습니다.
  5. 5프로젝트 전체 — 모든 탭의 JSON · 설명서와 설정(탭 순서 · 보기)을 zip 하나로. 다시 불러오면 그대로 열립니다.
  6. 6GitHub에 커밋 — 고친 내용을 팀 저장소에 올립니다. 팀으로 쓰기 참고.
  7. 7엑셀 · CSV — 기본은 이름 줄 + 값만 있는 표입니다. 체크로 타입 줄 · 설명 · ID 접두사를 더합니다.
    자세히
    엑셀은 탭마다 시트 하나, 설명은 이름_Meta 시트(CSV는 파일)로 들어갑니다. CSV는 탭마다 파일 하나, 여럿이면 zip. 고른 체크는 프로젝트마다 기억하고, 다시 불러오면 타입 · 설명까지 돌아옵니다.

자세히

3로그인 (각자)

☰ → GitHub 로그인 → GitHub로 로그인 → GitHub 화면에서 Authorize.

자세히

자세히

탭 · 테이블

탭 줄 오른쪽 + · ↻ · ⚙새 테이블 · 갱신 · 테이블 설정(이름 · 복제 · 보기 방향 · 잠금 · 삭제)
잠금 (⚙)칸 · 컬럼 · 이름을 못 고치게 합니다. 이 브라우저에만 저장됩니다
탭 우클릭 · 더블클릭이름 바꾸기 · 삭제
탭을 꾹 눌러 끌기 · 탭 줄에서 휠탭 순서 바꾸기 · 넘기기
컬럼 이름 칸을 꾹 눌러 끌기열 순서 바꾸기 (ID는 맨 앞 고정)
열의 ✕열 삭제 (Ctrl+Z로 되돌림)
도구줄 데이터 조회ID를 적으면 같은 ID의 테이블을 하나로 합친 오브젝트(Unity에서 구운 모양)와, 그 ID를 쓰는 곳을 봅니다
자세히
숫자를 치면(또는 숫자가 적힌 칸을 누르면) 그 숫자로 시작하는 ID가 작은 순서로 펼쳐지고, 누르거나 ↑↓ + Enter로 고릅니다. 결과는 정확히 같은 ID만 찾습니다(item_1011처럼 접두사를 붙여도 됨).
오브젝트는 그 ID의 행에, 그 테이블을 ID로 참조한 테이블의 행을 합친 것입니다. 같은 이름 · 같은 값은 한 줄로, 값이 다르면 노란 줄로 보입니다. 조회 창은 보기만 하고, 줄을 누르면 표의 그 칸으로 가서 거기서 고칩니다. 이름이 ID로 끝나는 칸의 번호는 누르면 그 ID로 다시 조회합니다. 쓰는 곳은 이름이 ID로 끝나는 열(ItemID 등)에 그 번호가 적힌 줄이고, 누르면 그 칸으로 갑니다.
목록에서 고르거나 칸으로 간 ID는 처음 화면의 최근에 남습니다(프로젝트마다 이 브라우저에).
