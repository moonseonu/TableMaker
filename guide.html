표 만들기

엑셀처럼 칸에 바로 적습니다. 점선으로 된 빈 칸에 적으면 그 순간 새 열·새 행이 됩니다.

  1. 1새 열 — 맨 오른쪽 점선 칸에 컬럼 이름을 적으면 열이 생깁니다. 이름 대신 값부터 적어도 되고, 그러면 col1 같은 임시 이름이 붙습니다(위로 올라가 이름을 고치면 됩니다). 비워 두면 JSON에 나오지 않습니다. 머리줄은 이름 줄과 그 아래 타입 줄(타입·버튼)로 나뉘고(세로 보기에서는 왼쪽의 이름 열·타입 열), 이름이 길면 그 길이만큼 열이 저절로 넓어집니다.
  2. 2새 행 — 맨 아래 점선 줄에 적으면 행이 생깁니다. Name처럼 ID가 아닌 칸부터 적으면 ID는 가장 큰 번호의 다음 번호가 자동으로 붙습니다. 마지막 행에서 Enter를 치면 그 줄로 내려가고, 긴 표에서는 Ctrl+↓로 한 번에 갑니다.
  3. 3열 타입 — ID · String(문자열) · Int(정수) · Float(실수) · Bool(참/거짓) · Enum(정해진 값 중 하나). 드롭다운에 마우스를 올리면 타입 설명이 보입니다. JSON에 그 타입 그대로 나갑니다("900"이 아니라 900). 새로 만든 열은 처음 적은 값을 보고 타입이 자동으로 정해지고, 드롭다운에서 언제든 바꿀 수 있습니다. 타입을 바꿔도 칸의 값은 그대로이고, 맞지 않는 값만 빨간 칸으로 알려줍니다(Bool 열은 값이 true · false · 빈칸일 때만 체크박스).
    Enum은 엑셀처럼 칸에 바로 적습니다. 그 열에 적힌 값들이 곧 값 목록이고, 앞 글자만 쳐도 나머지가 흐리게 보여 Enter·Tab으로 채워집니다(그대로 두려면 Backspace나 Delete). 옆의 ⚙를 누르면 지금 목록이 보입니다. 잘못 적은 값은 칸을 고치면 목록에서도 사라집니다. JSON에는 글자로 나갑니다.
  4. 4빨간 칸 — 타입에 맞지 않는 값입니다(위 표의 천원). 위쪽에 오류 개수가 뜨고, 고치면 사라집니다.
칸 고르기와 고치기 (엑셀과 같음) — 칸을 클릭하면 고른 상태가 되고, 화살표로 옆 칸으로 움직입니다. 그대로 타이핑하면 기존 값을 지우고 새로 쓰고, 기존 값을 일부만 고치려면 더블클릭이나 F2. 고치던 것은 Esc로 취소, 고른 칸은 Delete로 비웁니다. 여러 칸은 드래그해서 고르고(컬럼 이름 칸이나 행 번호를 끌면 열·행 통째로) Ctrl+C로 복사하거나 Delete로 한꺼번에 비우며, 잘못 고친 것은 Ctrl+Z로 되돌립니다. 열 순서는 컬럼 이름 칸을 꾹 눌러 끌어서 바꿉니다. 키 전체는 보기 · 단축키에 있습니다.
이미 엑셀로 만든 표가 있다면 — 엑셀에서 Ctrl+A, Ctrl+C 한 뒤 TableMaker의 빈 곳을 누르고 Ctrl+V. 첫 줄이 컬럼 이름이 되고, 값을 보고 열 타입을 알아서 정합니다. 엑셀이 붙이는 1,000 같은 쉼표와 TRUE/FALSE도 알아봅니다.

ID 규칙

첫 열이 ID입니다. JSON에는 정수로 나가고, 행은 항상 ID 순서로 정렬됩니다.

  1. 1ID는 정수 — 번호에 의미를 담는 방식(1011 씨앗, 1012 작물…)을 그대로 씁니다. 비었거나, 숫자가 아니거나, 다른 행과 겹치면 빨간 칸입니다.
  2. +번호 이어서 적기 — ID 칸에 1001을 적고 Enter를 치면 맨 아래 빈 줄에 1002가 미리 채워집니다. 그대로 Enter면 1002 행이 생기고, 2001처럼 다른 번호를 치면 그다음부터 2002, 2003…으로 이어집니다. 이미 있는 번호는 건너뜁니다.
  3. 2⚙ 접두사 — item_처럼 적으면 칸 앞에 이름표가 붙어 어떤 테이블의 ID인지 보입니다. 화면에만 붙고 JSON에는 1001로 나갑니다. JSON에 포함을 켜면 "item_1001" 문자로 나갑니다. 설정이 있으면 ⚙가 파랗게 보입니다.
  4. 3정렬 — ▼ 오름차순, ▲ 내림차순. 번호를 적고 칸을 떠나면 그 행이 순서에 맞는 자리로 갑니다.
  5. 4노란 칸 — 다른 테이블이 같은 자릿수의 ID를 쓰고 있다는 알림입니다(위 표의 2001). 테이블마다 100단위, 1000단위처럼 자릿수를 나눠 쓰면 겹치지 않습니다. 저장은 막지 않습니다.
ID가 없는 테이블 — Config처럼 한 줄짜리 설정 테이블은 ID 열을 지우면 됩니다. 다른 열의 타입을 ID로 바꾸면 그 열이 맨 앞으로 가서 ID가 됩니다.

  1. 1켜기 — ID 열의 ⚙ → 다른 테이블 참조를 체크하면, 이 테이블의 ID가 들어 있는 테이블이 자동으로 골라집니다. 아래 목록에서 체크로 바꿀 수 있고, 여러 개도 됩니다(예: CostDataTable → StructureDataTable + UnitDataTable). 대상도 탭으로 열려 있어야 합니다.
  2. 2🔗 자동으로 가져온 열 — 대상에도 있는 이름의 열(Name)은 같은 ID 행의 값으로 채워지고 회색으로 잠깁니다. 대상에서 고치면 여기도 바뀌고, JSON에도 그 값으로 나갑니다.
  3. 3🔗 끄기 — 파란 🔗를 누르면 연결이 끊겨 직접 고칠 수 있습니다. 연결 전에 적어 둔 값이 있었다면 그 값으로 돌아갑니다. 다시 누르면 대상 값으로 채워집니다.
  4. 4없는 ID — 고른 대상 어디에도 없는 번호는 노란 경고 칸입니다(1099). 오타나 지워진 아이템을 찾을 때 씁니다. 이 테이블에만 일부러 둔 행이면 칸을 우클릭 → 이 경고 숨기기로 숨길 수 있고(다시 우클릭하면 되살리기), 오류로 치지 않아 저장도 그대로 됩니다.

  1. 1적기 — 위쪽 테이블 설명 버튼을 누르면 아래에 창이 열립니다. 테이블 설명과 컬럼별 설명을 적습니다. Enum 열은 타입 칸의 Enum · N개 ▾를 누르면 값 목록이 아래로 펼쳐집니다.
  2. 2엑셀 Meta 시트 붙여넣기 — Column · Description · Type 형식의 시트를 복사해 이 창에 붙여넣으면 한 번에 채워집니다. 컬럼명 · 설명 · 타입처럼 한국어 머리줄도 알아봅니다.
  3. 3설명서 내보내기 — 파일 저장 ▾ → 설명서 (.md)…. 오른쪽 같은 문서가 만들어져 프로그래머에게 넘기거나 커밋에 함께 넣을 수 있습니다.
  4. 4설정 되살리기 — JSON과 같은 이름의 .md를 함께 불러오면 설명과 함께 열 타입·접두사·참조 설정도 돌아옵니다.

불러오기 · 저장

테이블을 불러오면 지금 탭은 그대로 두고 새 탭으로 더합니다. 설명은 지금 탭에 붙입니다.

테이블 (새 탭으로)
설명 (Meta)
  1. 1불러오기 ▾ → 파일 — JSON · CSV · 설명서(.md) · zip을 여러 개 함께 고를 수 있습니다. 한국어 엑셀이 저장한 CSV도 글자가 깨지지 않습니다.
    엑셀(.xlsx)을 고르면 시트 목록 표가 떠서, 체크한 시트만 시트마다 새 탭으로 열립니다. 맨 위 체크박스로 모두 고르기·모두 풀기, 줄을 눌러도 체크가 바뀝니다. 수식 칸은 계산된 값으로 들어오고, 맨 위에 제목 줄이 있으면 건너뜁니다. 컬럼 이름 바로 아래(또는 위) 줄에 int · string · enum 같은 타입을 적어 둔 시트는 그 타입대로 가져오고, 없으면 값으로 짐작합니다(글자가 여러 행에 반복되는 열은 Enum). CSV와 붙여넣은 표도 같습니다. ItemDataTable_Meta 같은 설명 시트도 목록에 그대로 보이고 따로 읽지 않습니다. 컬럼 설명은 그 시트를 복사해 테이블 설명 창에 붙여넣어 주세요. 뒤 시트의 ID가 앞 시트들에 모두 있으면(예: Cost의 ID가 Structure·Unit에 다 있음) 다른 테이블 참조가 저절로 이어집니다. 이름이 같은 열은 값이 같을 때만 🔗로 연결하고, 다르면 엑셀 값을 그대로 둡니다.
    불러온 표는 늘 새 탭으로 열리고, 이미 있는 이름이면 ItemDataTable_2처럼 번호가 붙습니다. 엑셀은 시트 목록 창에서 이름이 겹치는 시트 아래에 이름 칸이 나와, 가져오기 전에 바로 고칠 수 있습니다. 아무것도 적지 않은 처음 탭 하나만 있을 때 불러오면 그 탭은 치우고 불러온 것만 남깁니다.
  2. 2불러오기 ▾ → 폴더 — Unity 프로젝트의 Json 폴더를 통째로 고르면 안의 테이블이 한 번에 열립니다. 윈도우 창에는 폴더만 보이니, 고른 뒤 폴더 안 파일 목록(파일 · 종류 · 크기 · 들어갈 곳)이 떠서 체크한 것만 불러옵니다. 짝이 없는 설명서는 처음엔 체크가 빠져 있습니다. 폴더에서는 파일이 이름 순서로 열리니, 열린 뒤 탭을 끌어 순서를 바꾸세요. .meta 같은 다른 파일은 건너뜁니다.
  3. 3불러오기 ▾ → 설명 (Meta) — 설명서(.md)의 테이블 설명과 컬럼 설명·타입을 이미 있는 탭에 붙입니다(새 탭은 만들지 않습니다). 파일을 하나만 고르면 이름과 상관없이 지금 보고 있는 탭에(메뉴에 어느 탭인지 보입니다), 여러 개를 고르거나 폴더를 고르면 저마다 이름이 같은 탭에 붙습니다(폴더는 먼저 안의 설명서 목록이 떠서 고른 것만). 이름은 파일 이름 → 끝의 _Meta를 뗀 이름 → 설명서 맨 위 # 제목 순서로 찾고, 결과와 짝이 없는 설명서는 잠깐 뜨는 알림으로 보여 줍니다(마우스를 올리면 멈추고, 누르면 닫힙니다). 이 툴이 저장한 설명서는 ID 접두사·참조 설정까지 되살아나고, 다른 곳에서 만든 설명서도 표 머리줄에 컬럼 · 설명 · 타입(또는 Column · Description · Type) 같은 이름이 있으면 열 순서와 상관없이 읽습니다. 탭에 없는 컬럼도 그 알림에 나옵니다. JSON과 이름이 같은 설명서를 파일로 함께 고르면 지금처럼 그 테이블에 저절로 붙습니다.
  4. 4파일 저장 ▾ — JSON…·설명서…를 누르면 탭 목록 표가 떠서 저장할 탭을 고릅니다(처음엔 지금 탭만 체크, 맨 위 체크박스로 모두). 하나면 파일 하나, 여러 개면 zip 하나로 받습니다. 고른 탭에 오류가 있으면 "그래도 저장할까요?" 확인 창이 뜹니다.
  5. 5프로젝트 전체 (.zip) — 모든 탭의 JSON과 설명서를 묶습니다. 맨 위에 설정 메모 _TableMaker.md도 들어가는데, 탭 순서 · 행/열 바꿔 보기 · 숨긴 경고가 적혀 있어 사람이 읽어도 되고, 이 zip(또는 압축을 푼 폴더)을 다시 불러오면 그 설정 그대로 열립니다. 압축을 풀면 JSON은 게임 폴더에 바로 넣고, 그대로 다시 불러와 이어서 작업할 수 있습니다.

보기 · 단축키

열이 아주 많은 테이블은 행과 열을 바꿔 세로로 볼 수 있습니다.

⇄1 1
  1. 1⇄ 행/열 바꿔 보기 — 표 왼쪽 위 모서리. Config처럼 한 줄에 열이 수십 개인 테이블을 위아래로 훑어볼 수 있습니다. 보는 방향만 바뀌고 JSON은 그대로이며, 테이블마다 따로 기억합니다. 행이 수천 개인 테이블은 가로 보기가 훨씬 빠릅니다(가로 보기는 화면에 보이는 행만 그립니다).
  2. 1︽ 타입 줄 접기 — ⇄ 바로 옆 버튼. 타입 줄(세로 보기에서는 타입 열, 버튼은 «)을 통째로 접어 값만 보이게 합니다. 접혀 있는 동안 열 삭제 ✕는 컬럼 이름 칸 오른쪽 끝에 나오고, 타입을 바꿀 때는 ︾(»)로 다시 펴세요. 접은 상태는 이 브라우저에 기억됩니다.

컬럼 이름 칸을 꾹 눌러 끌기열 순서 바꾸기. 0.4초 누르면 열이 흐려지고, 끌면 파란 선이 끼울 자리를 보여줍니다. 놓으면 그 자리로 옮겨지고 JSON 키 순서도 바뀝니다(Ctrl+Z로 되돌리기). ID 열은 맨 앞 고정, 세로 보기(⇄)에서는 위아래로 끕니다
탭 끌기탭 순서 바꾸기. 다른 탭의 앞·뒤에 놓습니다(파란 세로줄). 여러 탭 zip · 프로젝트 전체 zip도 이 순서로 저장되고, 프로젝트 zip을 다시 열면 이 순서로 열립니다
탭 더블클릭 · 탭·열의 ✕테이블 이름 바꾸기 · 테이블·열 삭제 (확인 창에서 삭제를 누르면 지워지고, Ctrl+Z로 되돌릴 수 있습니다)
Ctrl+C고른 칸(범위)을 복사. 엑셀에 붙여넣으면 표 모양 그대로 들어갑니다
Ctrl+Z · Ctrl+Y되돌리기 · 다시 하기 (최근 100번까지. 한 칸에 이어서 친 것은 한 번으로)
Enter · ↓아래 칸. 마지막 행에서는 맨 아래 빈 줄로. ID 칸이면 다음 번호(1001 → 1002)가 미리 채워집니다
Shift+Enter · ↑위 칸. 첫 행에서는 컬럼 이름 칸으로
← · →옆 칸. 마지막 열 다음은 빈 열 칸으로 (값부터 적으면 col1 같은 임시 이름이 붙습니다)
세로 보기(⇄)에서↑↓ · Enter는 컬럼 사이, ←→는 행 사이를 움직입니다. 마지막 컬럼에서 Enter·↓를 누르면 맨 아래 + 새 열 줄로 가서 바로 새 열을 적을 수 있고, 맨 왼쪽에서 ←를 누르면 컬럼 이름 칸으로 갑니다
Ctrl+↓맨 아래 빈 줄로 한 번에 (긴 표에서 새 행 넣을 때)
Shift+마우스 휠표를 옆으로 스크롤
Ctrl+V칸을 고른 채로: 그 칸부터 채움 (범위를 골랐으면 범위 왼쪽 위부터, 한 값이면 범위 전체를 그 값으로) · 빈 테이블에: 표 전체로 · 빈 곳에서: 새 테이블 · 테이블 설명 창에서: Meta 시트로 읽기

이용 안내

TableMaker를 쓰기 전에 알아두면 좋은 점입니다.

프로젝트

제목줄 왼쪽의 프로젝트 이름을 누르면 프로젝트를 바꾸거나, 새로 만들거나, 이름을 바꾸고 지울 수 있습니다. 새로 만들 때 엑셀·JSON 파일을 같이 고르면 바로 불러오고, 처음 열면 이 창으로 시작합니다. 탭 묶음은 프로젝트마다 따로 저장됩니다.

데이터는 내 브라우저에만

입력한 표는 서버로 보내지 않고 지금 쓰는 브라우저에만 저장됩니다. 가입도 필요 없습니다.

백업은 직접

브라우저 데이터를 지우거나 다른 PC로 옮기면 표가 보이지 않습니다. 중요한 작업은 파일 저장 ▾ → 프로젝트 전체 (.zip)로 받아 두세요.

무료

모든 기능을 무료로 쓸 수 있습니다. 만든 데이터는 상업용 게임을 포함해 자유롭게 쓰면 됩니다. 도움이 됐다면 ☰ 메뉴의 ☕ 커피 한 잔 후원으로 응원해 주세요.

새 버전

업데이트가 올라오면 화면 맨 위에 새 버전 띠가 뜹니다. 누르면 새로고침되고, 작업한 표는 그대로 남습니다. 지금 버전은 ☰ 메뉴 맨 아래에 있습니다.

권장 브라우저

크롬, 엣지 최신 버전에서 가장 잘 동작합니다. 표 편집은 PC 화면을 기준으로 만들었습니다.
