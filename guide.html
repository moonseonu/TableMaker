  1. 1새 열 — 맨 오른쪽 점선 칸에 컬럼 이름을 적으면 열이 생깁니다. 값부터 적으면 col1 같은 임시 이름이 붙으니 나중에 고치세요. 비워 둔 열은 JSON에 나오지 않습니다.
  2. 2새 행 — 맨 아래 점선 줄에 적으면 행이 생깁니다. ID가 아닌 칸부터 적으면 다음 번호가 자동으로 붙습니다. 긴 표에서는 Ctrl+↓로 그 줄에 바로 갑니다.
  3. 3열 타입 — ID · String(문자열) · Int(정수) · Float(실수) · Bool(참/거짓) · Enum(정해진 값 중 하나). JSON에 그 타입 그대로 나갑니다("900"이 아니라 900). 새 열은 처음 적은 값을 보고 타입이 정해지고, 드롭다운에서 언제든 바꿀 수 있습니다. 바꿔도 값은 그대로이고, 맞지 않는 값만 빨간 칸이 됩니다.
    Enum — 그 열에 적힌 값들이 곧 목록입니다. 앞 글자만 쳐도 나머지가 흐리게 보여 Enter · Tab으로 채워지고, ⚙를 누르면 목록이 보입니다. JSON에는 글자로 나갑니다.
  4. 4빨간 칸 — 타입에 맞지 않는 값입니다(위 표의 천원). 위쪽에 오류 개수가 뜨고, 고치면 사라집니다.
  5. 5문A 번역해서 채우기 — String 열에만 있습니다. 누르면 다른 열(예: Korean)을 번역해 이 열(예: English)의 모든 칸을 채웁니다. 원문 열과 번역할 언어만 고르면 되고, 원문 언어는 글을 보고 알아냅니다. 이미 적힌 칸이 있으면 덮어쓰기 전에 묻고, Ctrl+Z 한 번으로 모두 되돌립니다. 지금은 브라우저 내장 번역(무료, 글이 PC 밖으로 나가지 않음)이라 Chrome PC에서만 되고, 처음 한 번은 언어 파일을 받습니다. 기계 번역이니 한 번 확인해 주세요.
칸 고르기와 고치기 (엑셀과 같음) — 칸을 클릭해 고르고 화살표로 움직입니다. 그대로 타이핑하면 새로 쓰고, 일부만 고치려면 더블클릭이나 F2. Esc 취소, Delete 비우기, Ctrl+Z 되돌리기. 여러 칸은 드래그해서 고릅니다(컬럼 이름 칸 · 행 번호를 끌면 열 · 행 통째로). 열은 글자에 맞춰 넓어지고, 컬럼 이름 칸의 오른쪽 경계를 끌어 너비를 정하거나 두 번 눌러 되돌립니다. 키 전체는 보기 · 단축키에 있습니다.
이미 엑셀로 만든 표가 있다면 — 엑셀에서 Ctrl+A, Ctrl+C 한 뒤 GameTableMaker의 빈 곳을 누르고 Ctrl+V. 첫 줄이 컬럼 이름이 되고, 값을 보고 열 타입을 알아서 정합니다. 엑셀이 붙이는 1,000 같은 쉼표와 TRUE/FALSE도 알아봅니다.

ID 규칙

첫 열이 ID입니다. JSON에는 정수로 나가고, 행은 항상 ID 순서로 정렬됩니다.

  1. 1ID는 정수 — 번호에 의미를 담는 방식(1011 씨앗, 1012 작물…)을 그대로 씁니다. 비었거나, 숫자가 아니거나, 다른 행과 겹치면 빨간 칸입니다.
  2. +번호 이어서 적기 — ID 칸에 1001을 적고 Enter를 치면 맨 아래 빈 줄에 1002가 미리 채워집니다. 2001처럼 다른 번호를 치면 그다음부터 2002…로 이어지고, 이미 있는 번호는 건너뜁니다.
  3. 2⚙ 접두사 — item_처럼 적으면 칸 앞에 이름표가 붙어 어떤 테이블의 ID인지 보입니다. 화면에만 붙고 JSON에는 1001로 나갑니다. JSON에 포함을 켜면 "item_1001" 문자로 나갑니다. 설정이 있으면 ⚙가 파랗게 보입니다.
  4. 3정렬 — ▼ 오름차순, ▲ 내림차순. 번호를 적고 칸을 떠나면 그 행이 순서에 맞는 자리로 갑니다.
  5. 4노란 칸 — 다른 테이블이 같은 자릿수의 ID를 쓰고 있다는 알림입니다(위 표의 2001). 테이블마다 100단위, 1000단위처럼 자릿수를 나눠 쓰면 겹치지 않습니다. 저장은 막지 않습니다.
  6. 5⚙ 첫 자리로 색 구분 — ID 첫 자리(1~9)마다 색을 정해 ID 칸 옆에 얇은 띠로 보여 줍니다. 1xxx 씨앗 · 8xxx 업그레이드처럼 첫 자리로 종류를 나눈 표에서 구간이 한눈에 보이고, 잘못 매긴 번호가 튑니다. 아래 동그라미는 색과 자리의 짝입니다(이 표에 없는 자리는 테두리만). 화면에만 보이고, 테이블마다 켜고 끕니다.
ID가 없는 테이블 — Config처럼 한 줄짜리 설정 테이블은 ID 열을 지우면 됩니다. 다른 열의 타입을 ID로 바꾸면 그 열이 맨 앞으로 가서 ID가 됩니다.

  1. 1켜기 — ID 열의 ⚙ → 다른 테이블 참조를 체크하면, 이 테이블의 ID가 들어 있는 테이블이 자동으로 골라집니다. 아래 목록에서 체크로 바꿀 수 있고, 여러 개도 됩니다(예: CostDataTable → StructureDataTable + UnitDataTable). 대상도 탭으로 열려 있어야 합니다.
  2. 2🔗 자동으로 가져온 열 — 대상에도 있는 이름의 열(Name)은 같은 ID 행의 값으로 채워지고 회색으로 잠깁니다. 대상에서 고치면 여기도 바뀌고, JSON에도 그 값으로 나갑니다.
  3. 3🔗 끄기 — 파란 🔗를 누르면 연결이 끊겨 직접 고칠 수 있습니다. 연결 전에 적어 둔 값이 있었다면 그 값으로 돌아갑니다. 다시 누르면 대상 값으로 채워집니다.
  4. 4없는 ID — 고른 대상 어디에도 없는 번호는 노란 경고 칸입니다(1099). 오타나 지워진 아이템을 찾을 때 씁니다. 일부러 둔 행이면 칸 우클릭 → 이 경고 숨기기(다시 우클릭하면 되살리기). 오류가 아니라 저장은 그대로 됩니다.

  1. 1적기 — 위쪽 테이블 설명 버튼을 누르면 아래에 창이 열립니다. 컬럼 설명 칸은 ↓ · Enter · Tab으로 다음 칸, ↑ · Shift+Enter · Shift+Tab으로 이전 칸입니다. Enum 열은 Enum · N개 ▾를 누르면 값 목록이 펼쳐집니다.
  2. 2엑셀 Meta 시트 붙여넣기 — Column · Description · Type 형식의 시트를 복사해 이 창에 붙여넣으면 한 번에 채워집니다. 컬럼명 · 설명 · 타입처럼 한국어 머리줄도 알아봅니다.
  3. 3설명서 내보내기 — 파일 저장 ▾ → 설명서 (.md)…. 오른쪽 같은 문서가 만들어집니다. 파일 이름은 ItemDataTable_Desc.md처럼 뒤에 _Desc가 붙습니다(JSON과 이름이 같으면 Unity Resources.Load가 헷갈려서). 예전 이름(ItemDataTable.md)도 불러오고, 커밋하면 새 이름으로 바꿔 올립니다.
  4. 4설정 되살리기 — JSON과 그 설명서(이름_Desc.md, 예전 이름.md)를 함께 불러오면 설명과 함께 열 타입·접두사·참조 설정도 돌아옵니다.

불러오기 · 저장

어디서 가져오든 같은 목록 창이 떠서, 파일마다 들어갈 곳(새 탭 · 설명 · 설정)을 먼저 짐작해 보여 줍니다. 지금 탭은 덮어쓰지 않습니다.

  1. 1GitHub — 팀 저장소의 폴더에서 바로 가져옵니다. 로그인 · 연결 · 갱신은 팀으로 쓰기에 정리했습니다.
  2. 2파일 — 여러 개를 함께 고를 수 있습니다. JSON · CSV 하나만 고르면 목록 창 없이 바로 새 탭으로 열립니다.
  3. 3폴더 — Unity의 Json 폴더를 통째로 고르면 안의 파일이 목록에 나옵니다(.meta · 엑셀은 뺌). 이름 순서로 열리니 탭을 끌어 순서를 바꾸세요.
  4. 4JSON… · 설명서… — 저장할 탭을 고릅니다. 하나면 파일 하나, 여러 개면 zip 하나. 오류가 있으면 먼저 묻습니다.
  5. 5프로젝트 전체 — 모든 탭의 JSON · 설명서와 설정 메모 _TableMaker.md(탭 순서 · 보기 · 숨긴 경고)를 zip 하나로. 다시 불러오면 그대로 열립니다.
  6. 6GitHub에 커밋 — 고친 내용을 팀 저장소에 올립니다. 팀으로 쓰기 참고.

팀으로 쓰기 (GitHub)

프로젝트를 팀 저장소의 폴더에 연결하면, 누가 커밋했을 때 다른 사람 화면에 알림이 뜨고 ↻ 한 번으로 같은 탭이 새 내용으로 바뀝니다. 서버 없이 GitHub만 씁니다.

처음 한 번

1저장소 준비

GitHub에 저장소를 만듭니다(내 계정이든 조직이든 됩니다). 만들 때 Add a README file을 체크하면 빈 저장소가 아니라서 문제가 없습니다. 팀원은 저장소 Settings → Collaborators(조직이면 조직)에 초대합니다.

2앱 설치 (저장소 주인, 한 번)

저장소 주인이 GameTableMaker 앱을 설치하고 쓸 저장소를 고릅니다. 처음 GitHub로 로그인하면 Authorize 다음에 설치 화면이 바로 이어집니다. 팀원이 초대한 저장소만 쓴다면 앱 설치 없이 로그인을 누르세요(주인에게 설치를 부탁하는 안내가 뜹니다). 앱은 고른 저장소의 파일 읽기 · 쓰기만 합니다.

3로그인 (각자)

☰ → GitHub 로그인 → GitHub로 로그인을 누르고 GitHub 화면에서 Authorize를 누르면 돌아옵니다. 토큰을 만들 필요가 없습니다. 로그인 유지(기본 켬)를 끄면 탭을 닫을 때 로그아웃됩니다. 직접 만든 토큰을 쓰고 싶으면 같은 창의 고급: 토큰으로 로그인.

4연결

불러오기 ▾ → GitHub으로 저장소 · 브랜치 · 폴더를 고르면 가져오면서 연결됩니다. 처음 올리는 사람은 파일 저장 ▾ → GitHub에 커밋으로 연결해도 됩니다. 이미 작업하던 표가 있으면 같은 창의 현재 표로 연동을 누르세요. 탭은 그대로 두고 연결만 하고, GitHub에만 있는 표는 받아 옵니다.

  1. 4내가 고친 파일만 · 신규 · 수정 · 삭제 — 마지막 갱신 뒤 고친 파일만 올라가서, 팀원이 고친 파일을 옛 내용으로 되돌리지 않습니다. 이름만 바뀐 파일은 수정으로 나오고 옆에 예전 이름이 보입니다. 여기서 지운 표는 삭제로 GitHub에서도 지워집니다. 들여쓰기 같은 글자 모양 차이는 바뀐 것으로 치지 않습니다.
  2. 5⚠ 팀원도 고친 파일 — 올리면 팀원 변경을 덮어써서 체크가 빠져 있습니다. 먼저 ↻로 받은 뒤 다시 고쳐 올리는 게 안전합니다.
  3. 6저장소 · 브랜치 · 폴더 — 연결된 저장소로 채워져 열립니다. 바꾸면 아래 목록이 그 폴더 기준으로 다시 계산되고, 폴더 목록 맨 아래 + 새 폴더…로 새 폴더도 만듭니다.
  4. 7커밋 메시지 — 고른 파일에 맞춰 자동으로 적힙니다. 바뀐 칸 수와 ⚠ 컬럼 삭제 · 이름 · 타입 변경처럼 프로그래머가 알아야 할 변경이 들어가니, 필요하면 이유를 덧붙여 주세요.
알아 둘 것 — 그사이 누가 먼저 커밋했으면 덮어쓰지 않고 알려 줍니다. GitHub에서만 지운 파일은 여기가 원본이라, 다음 커밋 때 다시 올라갑니다. ↻는 연결된 폴더 바로 아래 파일만 맞추고, 같은 탭을 둘이 고치면 칸끼리 합치지 않고 파일 하나를 고릅니다. 빈 저장소를 GitHub Desktop 등으로 먼저 받아 두었다면, 첫 커밋 뒤 다시 받아야 파일이 보입니다.

이용 안내

GameTableMaker를 쓰기 전에 알아두면 좋은 점입니다.

프로젝트

제목줄 왼쪽의 프로젝트 이름을 누르면 프로젝트를 바꾸거나 새로 만들고, 이름을 바꾸거나 지울 수 있습니다. 새로 만들 때는 빈 프로젝트 · 내 파일로 시작 · GitHub 저장소에서 중 하나를 고릅니다. 탭 묶음은 프로젝트마다 따로 저장됩니다.

메모

오른쪽 여백의 메모 칸에 커밋 메시지나 작업 기록을 적어 둡니다. 쓰는 대로 프로젝트마다 저장되고, 이 브라우저에만 남습니다(zip · 커밋에는 안 들어감). 화면이 좁으면(1100px 미만) 숨겨집니다.

데이터는 내 브라우저에만

입력한 표는 서버로 보내지 않고 지금 쓰는 브라우저에만 저장됩니다. 가입도 필요 없습니다. 저장 공간은 모든 프로젝트를 합쳐 글자 약 500만 자이고, 꽉 차면 알림이 뜹니다. 그동안은 저장되지 않으니 바로 zip으로 받아 두고 안 쓰는 프로젝트를 지우세요.

백업은 직접

브라우저 데이터를 지우거나 다른 PC로 옮기면 표가 보이지 않습니다. 중요한 작업은 파일 저장 ▾ → 프로젝트 전체 (.zip)로 받아 두거나 GitHub에 커밋하세요.

Safari에서 쓸 때

Safari(Mac · iPhone · iPad)는 이 사이트를 Safari를 쓴 날로 7일 동안 열지 않으면 저장된 표를 지울 수 있습니다(Apple 정책, 크롬 · 엣지에는 없음). Safari에서 쓴다면 GitHub에 커밋하거나 프로젝트 전체 (.zip)로 받아 두세요. 받아 둔 지 3일이 지나면 알림이 뜹니다. iPhone · iPad는 공유 → 홈 화면에 추가로 열면 이 규칙이 적용되지 않습니다.

무료

모든 기능을 무료로 쓸 수 있습니다. 만든 데이터는 상업용 게임을 포함해 자유롭게 쓰면 됩니다. 도움이 됐다면 ☰ 메뉴의 커피 한 잔 후원으로 응원해 주세요.

새 버전

업데이트가 올라오면 화면 맨 위에 새 버전 띠가 뜹니다. 누르면 새로고침되고, 작업한 표는 그대로 남습니다. 지금 버전은 ☰ 메뉴 맨 아래에 있습니다.

권장 브라우저

크롬, 엣지 최신 버전에서 가장 잘 동작합니다. 표 편집은 PC 화면을 기준으로 만들었습니다. 태블릿 · 휴대폰에서는 양옆 여백을 줄여 표를 더 넓게 보여 줍니다.
